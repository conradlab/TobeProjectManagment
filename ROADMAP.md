# Research Internship Roadmap

## Overview

This 12-week roadmap guides Tobe's computational research training at OHSU's Conrad Lab. The curriculum combines foundational technical skills with hands-on SATINN research and independent scientific proposal development.

**Expected time commitment:** 4-6 hours per week (this is a planning assumption, not a confirmed commitment).

---

## Program Structure

Three parallel tracks:

1. **Computational Foundations** (Weeks 1-3): Onboarding, Linux, Python, and Git
2. **SATINN Research & Development** (Weeks 5-12): Understanding and reimplementing SATINN in Python
3. **Independent Research** (Weeks 3-12): Developing Tobe's own scientific proposal

## How to Use This Repository

1. **Start here:** Read [README.md](README.md)
2. **Week 01:** Open [Issue #1](../../issues/1) and work through the checklist
3. **Each week:** Open the corresponding Issue and follow the tasks
4. **Blockers:** Use the [Blocker Issue Template](../.github/ISSUE_TEMPLATE/blocker.yml)
5. **Submit work:** Create pull requests and request mentor review
6. **Reflect:** Complete the reflection section at the end of each week

---

## Success Criteria

By the end of 12 weeks:

- [ ] Comfortable using Linux, SSH, and Prime8 independently
- [ ] Can write, test, and document Python code
- [ ] Understands machine learning fundamentals
- [ ] Comprehends SATINN architecture and research goals
- [ ] Implemented small Python components with testing
- [ ] Validated Python results against reference behavior
- [ ] Developed a scientifically coherent independent research proposal
- [ ] Ready to continue with next-phase research
