## WEEK 01: OHSU Institutional Onboarding

**Learning Objective:**
Successfully establish institutional access and communication channels required to participate in the Conrad Lab research program.

**Why This Week Matters:**
Before you can start scientific work, you need verified access to OHSU systems, secure communication with your mentors, and familiarity with the collaboration tools we use. This week ensures you can reliably reach Eisa and Don, submit work, and receive feedback.

**Prerequisites:**
- You have received a physical appointment letter or onboarding confirmation from OHSU.
- You have been provided with your OHSU NetID and temporary password.
- You have been given the invitation link to the Conrad Lab Microsoft Teams channel.
- Eisa or Don has verified you have their email addresses.

**Expected Time Commitment:**
6-8 hours (mostly waiting for activation and email delivery)

**Learning Objectives:**
1. Verify OHSU institutional credentials and access.
2. Understand multifactor authentication (MFA) and why it protects research.
3. Set up and test secure communication channels.
4. Become comfortable with GitHub Issues as a task-management tool.
5. Document setup completion without publishing sensitive details.

---

## Plan

### Step 1: Institutional Credentials (1–2 hours)
- [ ] Verify your OHSU NetID by attempting login at https://my.ohsu.edu
  - *Note: Your NetID is typically your first initial + last name (e.g., jtobe)*
- [ ] Set a permanent password (you will be prompted on first login)
- [ ] Document that you successfully logged in (screenshot login success without showing credentials)

### Step 2: Multifactor Authentication (1–2 hours)
- [ ] Enroll in OHSU MFA using the Duo Mobile app
  - Instructions: https://www.ohsu.edu/research/secure-login
  - Use your institutional email address
- [ ] Test MFA by logging out and logging back in
- [ ] Verify that you receive a Duo push notification on your registered device
- [ ] Document successful MFA setup (no screenshots of codes)

### Step 3: Institutional Email (1–2 hours)
- [ ] Access your OHSU email at https://outlook.office.com
  - Use your OHSU NetID: NetID@ohsu.edu
- [ ] Send a test email to yourself
- [ ] Send an introductory email to both Eisa and Don at their provided addresses
  - Include: your name, your role (high school research intern), week starting date
- [ ] Confirm that you can receive and read replies

### Step 4: Microsoft Teams Setup (30–60 minutes)
- [ ] Install Microsoft Teams (desktop or web app)
- [ ] Accept the invitation to the Conrad Lab channel
- [ ] Read the channel description and pinned resources
- [ ] Send a friendly "hello" message in the Conrad Lab team channel
- [ ] Confirm that your mentors can see your message (ask them to acknowledge)

### Step 5: GitHub and Issue Workflow (30–60 minutes)
- [ ] Ensure you can view this GitHub repository (read-only access is sufficient)
- [ ] Read the repository README
- [ ] Read the WEEKLY_PLANNER.md
- [ ] Understand how GitHub Issues and checkboxes work
  - Leave a comment on this Issue saying "I can see this Issue and understand the checklist format."
- [ ] If you have write access, practice checking a box and unchecking it to confirm the feature works

### Step 6: Verify All Access (30 minutes)
- [ ] Confirm you can log into OHSU NetID
- [ ] Confirm you can access OHSU email
- [ ] Confirm you received acknowledgment from Eisa or Don via email or Teams
- [ ] Confirm you can view this GitHub repository and understand the Issue structure
- [ ] Ask Eisa or Don via Teams or email: "Are there any additional onboarding requirements I have missed?"

## Reporting a Blocker

If you encounter a problem that prevents you from completing this week:

1. **Document the problem clearly:** What were you trying to do? What error or obstacle appeared?
2. **Note the timestamp:** When did this occur?
3. **Comment on this Issue** with the problem description, or
4. **Create a new GitHub Issue** with the label `blocker` describing the problem.

Your mentors will review blockers at least daily.
